# PQTunnel 2

A separate experimental development line for PQTunnel with post-quantum authentication and configurable TLS key exchange.

## Development status

This repository is being initialized. It is not production-ready and must not be used to protect sensitive activity until implementation, interoperability, network acceptance tests, and an independent security review are complete.

## Privacy in tests

Tests use synthetic documentation-only IP ranges, loopback addresses, and reserved example domains. Do not add operator-provided IP addresses, domains, hostnames, ports, tokens, credentials, certificates, private keys, or VPS details to source code, fixtures, logs, snapshots, examples, or CI configuration.
